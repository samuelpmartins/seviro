# Sons de Notificação

Este diretório deve conter o arquivo de som da notificação.

## Como adicionar o som

1. Baixe um arquivo de som de notificação (formato MP3 ou OGG)
   - Sugestão: https://notificationsounds.com/
   - Ou use: https://mixkit.co/free-sound-effects/notification/

2. Renomeie o arquivo para `notification.mp3`

3. Coloque o arquivo neste diretório

## Alternativa

O sistema JavaScript criará um beep sintético caso o arquivo não seja encontrado.
